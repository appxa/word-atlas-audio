# صداهای تکمیلی واژه‌نگار

فایل‌های صوتی تکمیلیِ مثال دوم واژه‌نگار؛ برای استفاده در برنامهٔ اندروید از طریق GitHub Pages منتشر می‌شوند. صداهای اصلی در مخزن `appxa/word-atlas` باقی می‌مانند.

منبع دریافت: `https://0xlei.tech/words/atlas/`. فهرست این منبع عنوان Word Atlas Open و مجوز CC BY 4.0 را ذکر می‌کند. فایل‌ها بدون تغییر دریافت شده‌اند؛ منبع پروژهٔ اصلی: Word Atlas contributors. وضعیت مجوز بازنشر فایل‌های تکمیلی که در مخزن اصلی موجود نیستند، به‌طور مستقل تأیید نشده است.

۶٬۲۸۷ فایل با اندازه و SHA-256 فهرست بسته‌های نسخهٔ اندروید تطبیق داده شده‌اند.
